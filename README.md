# Projeto de Design Profissional

Repositório criado como parte da atividade prática da trilha **GitHub Foundations** e da disciplina de Design Profissional.

## Objetivo do Projeto
Este repositório tem como objetivo consolidar os conhecimentos práticos de versionamento de código com **Git** e **GitHub**, aplicando conceitos como criação de branches, commits estruturados, pull requests/merges e documentação de projetos.

## O que foi aplicado
- **Controle de Versão:** Uso de Git local e remoto no GitHub.
- **Fluxo de Trabalho:** Criação de branch separada (`feature/`) para alterações e integração na branch principal (`main`) via Pull Request.
- **Organização:** Histórico de commits claros e descritivos.

## Tecnologias e Ferramentas
- Git
- GitHub
- Microsoft Learn (GitHub Foundations).
